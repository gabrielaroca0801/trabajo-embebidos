# Open-Source Automated Coffee Roaster (ESP32 + FreeRTOS)

Este repositorio contiene la documentación de hardware, esquemáticos, lista de materiales y el artículo científico del tostador automatizado de café desarrollado para la asignatura de Sistemas Embebidos de la Universidad del Cauca.

## Autores
* **Gabriel Fernando Aroca Albán** - garoca@unicauca.edu.co
* **Melissa Andrea Ordoñez Mora** - manordonez@unicauca.edu.co
* **Pablo Andrés Collazos Tobar** - pcollazost@unicauca.edu.co

## Estructura del Repositorio
* `/HardwareX_Tostador_Cafe.pdf`: Artículo completo formato HardwareX.
* `/SCH_Schematic1.png`: Diagrama esquemático en EasyEDA.
* `/BOM_Tostador.xlsx`: Lista detallada de componentes y costos.
